# Planeación

Aquí vivirá la **propuesta de roadmap** (Etapa G). Según el Prompt Maestro §12, es una propuesta para revisión y **no se convierte en plan definitivo sin aprobación del responsable**.

Cada unidad de entrega tendrá: objetivo, alcance, dependencias, especificación, diseño técnico, tareas, pruebas, criterios de aceptación, condiciones para comenzar y para terminar.
