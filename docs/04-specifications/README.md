# Especificaciones por funcionalidad

Una carpeta por módulo y un archivo por funcionalidad vertical: `docs/04-specifications/<modulo>/<feature>.md`, con la plantilla de la skill `quatreros-sdd-spec` (objetivo y alcance, RF/BR, modelo de datos, contrato de API, UI y estados, auditoría y eventos, criterios Gherkin, pruebas, condiciones de inicio y Definición de Terminado).
