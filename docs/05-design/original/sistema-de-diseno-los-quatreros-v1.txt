2. Tipografía y Estilos de Texto
Para garantizar compatibilidad con React + Tailwind CSS y legibilidad en pantallas táctiles o móviles de baja resolución:
Tipografía Principal: Inter o Plus Jakarta Sans (Sans-serif moderna con excelente x-height).
Tipografía Numérica (POS & Caja): JetBrains Mono (Monospaced para alineación perfecta de precios, cantidades y pesos).
Plaintext
Display Bold (28px / 32px)   -> Indicadores KPi, Totales POS, Encabezados Bento Grid
Title SemiBold (20px / 24px) -> Títulos de Cards, Nombres de Productos
Body Medium (14px / 20px)    -> Texto Operativo, Inputs, Opciones de Menú
Caption Regular (12px / 16px)-> Metadatos, Lotes FEFO, Timestamps
3. Componentes Clave & UI Kit
A. Botones (Button.tsx)
Primary Action (POS / Confirmar): Fondo #EA580C, texto #FFFFFF, bordes redondeados rounded-xl, sombra de brillo de brasa (shadow-orange-950/50), min-height de 52px para interacción táctil rápida sin margen de error.
Secondary Action: Fondo #27272A, borde 1px solid #3F3F46, texto #FFFFFF.
Ghost / Cancel: Borde transparente, texto #A1A1AA, hover a #27272A.
B. Cards & Bento Containers (Card.tsx)
Estructura: bg-[#18181B] border border-[#27272A] rounded-2xl p-5 shadow-xl transition-all duration-200.
Hover Effect: hover:border-[#EA580C]/50 hover:translate-y-[-2px].
C. Badges de Estado (Badge.tsx)
Lote Vencido: bg-red-500/10 text-red-400 border border-red-500/20
Lote FEFO Próximo: bg-yellow-500/10 text-yellow-400 border border-yellow-500/20
Entregado Parcial: bg-blue-500/10 text-blue-400 border border-blue-500/20
Paquete Abierto (Desglose): bg-orange-500/10 text-orange-400 border border-orange-500/20
D. Inputs & Controles Táctiles (Input.tsx / Keypad.tsx)
Campos numéricos con teclado gigante integrado (Big Numpad Overlay) para cajeros y personal con guantes o movilidad ágil. Altura mínima de input: 48px.

Flujo & UI Key:
Desglose Rápido: Si un producto individual se agota, el cajero presiona el botón "Abrir Paquete"; el sistema descuenta 1 paquete del inventario y suma 10 unidades individuales al POS en un toque.
Pago Mixto: Modal flotante para ingresar parciales (ej. $20,000 Efectivo + $44,000 Nequi) con cálculo automático de cambio.
